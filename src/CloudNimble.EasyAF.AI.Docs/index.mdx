# EasyAF.AI

EasyAF is how CloudNimble ships secure, scalable .NET applications quickly. EasyAF.AI is the layer that lets assistants use those applications the same way your own clients do: through open standards, against live data, with a catalog small enough to fit in a prompt.

The assistant speaks [Model Context Protocol](https://modelcontextprotocol.io). Your APIs stay [OData](https://www.odata.org). Nothing in the middle asks anyone to paste a spreadsheet into the chat.

## What "queryable AI" means here

A standards-based API is already queryable: `$filter`, `$expand`, `$select`, bound actions. EasyAF leans on that. EasyAF.AI makes the same API queryable **by an assistant** without teaching the model to read EDMX.

| Layer | Standard | Role |
|---|---|---|
| Data and HTTP | OData v4 | The API you already run. Filter, expand, page, act. |
| Assistant protocol | MCP 2.0 | How Claude, Cursor, and other harnesses call tools. |
| Catalog | OData MCP | Named tools and compact type cards built from `$metadata`. |
| Hosting | McpEssentials | Multi-user MCP servers with per-user task isolation. |
| Agent runtime | ClaudeEssentials | Strongly-typed hooks so Claude Code stays under your policy. |

The assistant spends tokens on the question. It does not chew through `$metadata` to guess how your service works.

## How the pieces fit

<Steps>
  <Step title="Ship an API the EasyAF way">
    EasyAF gives you the application shape: managers, OData/REST, audit, the bits that make a .NET backend fast to build and safe to run. That API is already a standard. EasyAF.AI does not replace it.
  </Step>
  <Step title="Give the assistant a protocol">
    MCP is how the assistant talks. [MCP Essentials](/mcpessentials) fills the gaps in the official C# SDK that show up the moment the server has more than one user: who started a task, who may poll it, where the snapshot lives.
  </Step>
  <Step title="Make the API queryable by that assistant">
    [OData MCP](/odata-mcp) reads `$metadata` once and hands the model a compact catalog. Local MCP runs on your machine against any OData service. Remote MCP ships on the API you host, at `{prefix}/mcp`.
  </Step>
  <Step title="Keep Claude Code honest in the repo">
    [ClaudeEssentials](/claudeessentials) is the hook surface for Claude Code: allow, deny, inject context, block a stop. Source-generated JSON, AOT-ready, no extra dependencies.
  </Step>
</Steps>
