## Summary

Wire payload for a resolved-input notification: task id, a newline, then request id.
Native channels (Redis pub/sub, Postgres `NOTIFY`) publish this string as-is.

## Remarks

Split is on the first newline so a request id may contain further newlines.
Task ids from [McpTaskStoreBase](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase) do not contain newlines.
