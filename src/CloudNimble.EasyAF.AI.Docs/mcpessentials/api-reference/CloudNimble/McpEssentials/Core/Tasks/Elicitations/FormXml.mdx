## Summary

Closed AOT codec for the compact `Form` / `Field` / `Option` island.
Uses [XmlWriter](https://learn.microsoft.com/dotnet/api/system.xml.xmlwriter) / [XmlReader](https://learn.microsoft.com/dotnet/api/system.xml.xmlreader). Does not use
`XmlSerializer`, sgen, or reflection over the form type.

## Remarks

Readers match [LocalName](https://learn.microsoft.com/dotnet/api/system.xml.xmlreader.localname) only. Writers emit `xmlns`
when `xmlNamespace` is supplied. DTD processing is prohibited. Comments are
ignored. Processing instructions inside `Form`, `Field`, or `Option`
are unexpected nodes.

## Examples

```csharp
var xml = FormXml.Serialize(form.ToDefinition());
var definition = FormXml.Parse(xml);
```
