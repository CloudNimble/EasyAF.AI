## Summary

An [IMcpTaskStorePlus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskStorePlus) that persists snapshots as Redis strings with
`PEXPIREAT` from [StoredMcpTask.DiscardAfter](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask#discardafter) and fans resolved input
over pub/sub.

## Remarks

Register as a singleton. The host owns `IConnectionMultiplexer`.
Native expiry is the drain; [McpTaskStoreBase.AutoSweep](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#autosweep) defaults to
[`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool). `WAIT` after create is off until
[RedisMcpTaskStore.WaitReplicas](/mcpessentials/api-reference/CloudNimble/McpEssentials/Redis/Tasks/RedisMcpTaskStore#waitreplicas) is positive. Eventually-consistent Redis without wait
is not SEP-2663 durable across nodes.
