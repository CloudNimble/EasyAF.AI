## Summary

An [IMcpTaskStorePlus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskStorePlus) that persists snapshots as PostgreSQL rows with
`LISTEN` / `NOTIFY` fan-out for resolved input.

## Remarks

Register as a singleton. The host owns `NpgsqlDataSource`.
[McpTaskStoreBase.AutoSweep](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#autosweep) defaults to [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool). Sweep is
`DELETE WHERE "DiscardAfter" &lt;= now`. Use Entity Framework Core with
`UseNpgsql` when the host already has a `DbContext`; this package exists
for Npgsql/Dapper hosts and for native notification.
