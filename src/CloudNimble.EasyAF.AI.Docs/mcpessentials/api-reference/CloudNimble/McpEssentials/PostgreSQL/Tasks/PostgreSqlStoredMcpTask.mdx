## Summary

One `McpTasks` row. Maps to [StoredMcpTask](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask) at the store boundary
and adds [PostgreSqlStoredMcpTask.RowVersion](/mcpessentials/api-reference/CloudNimble/McpEssentials/PostgreSQL/Tasks/PostgreSqlStoredMcpTask#rowversion) for compare-and-swap.
