## Summary

Persisted MCP task row. Inherits protocol fields from [StoredMcpTask](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask) and adds
an application-managed concurrency token plus JSON columns for payloads. Map with
`AddMcpTasksTable` (default table `McpTasks`). Do not store these rows
on domain tables; tasks expire in minutes.
