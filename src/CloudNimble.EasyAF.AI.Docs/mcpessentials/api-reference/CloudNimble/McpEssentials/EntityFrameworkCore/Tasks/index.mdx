## Types

### <Icon icon="file-brackets-curly" iconType="duotone" color="#419AC5" size={24} style={{ paddingRight: '8px' }} /> Classes

| Name | Summary |
| ---- | ------- |
| [EntityFrameworkAuthenticatedTaskStore](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/EntityFrameworkAuthenticatedTaskStore) | An [IPerUserMcpTaskStore](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IPerUserMcpTaskStore) that persists snapshots on  `TContext.Set&lt;McpTaskEntity&gt;()`. Register as a singleton. The host registers  *TContext* as scoped (standard `AddDbContext`); this store opens  a scope per operation. |
| [McpTaskEntity](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/McpTaskEntity) | Persisted MCP task row. Inherits protocol fields from [StoredMcpTask](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask) and adds  an application-managed concurrency token plus JSON columns for payloads. Map with  `AddMcpTasksTable` (default table `McpTasks`). Do not store these rows  on domain tables; tasks expire in minutes. |
| [McpTaskEntityConfiguration](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/McpTaskEntityConfiguration) | Maps [McpTaskEntity](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/McpTaskEntity) to a table (default `McpTasks`) with owner, work-window,  and discard indexes and an application-managed concurrency token. Protocol enums and payloads  convert to strings. [StoredMcpTask.DiscardAfter](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask#discardafter) stores UTC ticks so every  provider, including SQLite, can `ExecuteDelete` on the stamp. |
