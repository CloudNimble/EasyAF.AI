## Summary

Cosmos document for a task. [CosmosStoredMcpTask.Id](/mcpessentials/api-reference/CloudNimble/McpEssentials/Cosmos/Tasks/CosmosStoredMcpTask#id) is the Cosmos item id (the task id).
Partition key is [CosmosStoredMcpTask.OwnerUserId](/mcpessentials/api-reference/CloudNimble/McpEssentials/Cosmos/Tasks/CosmosStoredMcpTask#owneruserid).
