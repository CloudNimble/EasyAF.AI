## Summary

Cosmos serializer that uses source-generated [CosmosMcpTasksJsonContext](/mcpessentials/api-reference/CloudNimble/McpEssentials/Cosmos/Tasks/CosmosMcpTasksJsonContext)
with a reflection fallback for types the context does not list.
