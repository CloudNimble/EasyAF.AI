## Summary

An [IMcpTaskStorePlus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskStorePlus) that persists snapshots as Cosmos documents partitioned
by owner, with a task-id index for server-side complete and native document TTL.

## Remarks

Register as a singleton. The host owns [CosmosClient](https://learn.microsoft.com/dotnet/api/microsoft.azure.cosmos.cosmosclient).
Native TTL is the drain; [McpTaskStoreBase.AutoSweep](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#autosweep) defaults to
[`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool). Optional [IMcpTaskInputSignalBus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus) fans
elicitation wake-ups across nodes.
