| Exception | Description |

| `ArgumentNullException` | Thrown when *optionsBuilder* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Remarks

Use this from `AddDbContext` in the application project when the
[DbContext](https://learn.microsoft.com/dotnet/api/microsoft.entityframeworkcore.dbcontext) type lives in a library that must not reference this package.
The mapping runs after `OnModelCreating` on the same host context. Use
`ModelBuilder.AddMcpTasksTable` in `OnModelCreating` when the context project
already references this package. Pick one. Run `dotnet ef migrations add` with this
project as the startup project so the table is included. A migration from a project that
does not call this method will not see `McpTasks`.
