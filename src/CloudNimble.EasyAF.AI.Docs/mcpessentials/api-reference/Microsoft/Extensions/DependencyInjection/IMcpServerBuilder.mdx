#### Examples

```csharp
builder.Services.AddHttpContextAccessor();
builder.Services.AddDbContext&lt;AppDbContext&gt;(o =&gt; o.UseSqlServer(connectionString));
builder.Services.AddMcpServer()

    .WithEntityFrameworkTasks&lt;AppDbContext&gt;(
```
