## Intended how-to

<Steps>
  <Step title="Add the package">
    Add `McpEssentials.MongoDB`.
  </Step>
  <Step title="Create the collection">
    Collection `mcpTasks`, unique index on `taskId`, compound index `{ ownerUserId: 1, taskId: 1 }`.
  </Step>
  <Step title="Compare-and-swap">
    `findOneAndUpdate` filtered on current status.
  </Step>
  <Step title="Register the store">
    Singleton, same current-user factory as [Authenticated tasks](/mcpessentials/guides/authenticated-tasks).
  </Step>
</Steps>

## Events

Change streams on the collection, filtered to input-request updates. Subscribers raise `InputResponseReceived`.

## TTL

TTL index on the discard stamp (`DiscardAfter` / `CreatedAt + 2×TimeToLive`).
