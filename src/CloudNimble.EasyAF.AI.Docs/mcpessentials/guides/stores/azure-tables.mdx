Cheap point reads for task handles that live minutes. Weak queries. Pair with a queue or Service Bus for elicitation.

## When to use it

The host already uses Azure Table Storage and wants `PartitionKey = OwnerUserId`, `RowKey = TaskId`.

## Intended how-to

1. Add `McpEssentials.AzureTables`.
2. Table of tasks: `PartitionKey = OwnerUserId`, `RowKey = TaskId`.
3. Secondary index table `McpTaskIndex` with `PartitionKey = TaskId`, `RowKey = OwnerUserId` so server-side complete can find the owner.
4. Register the store as a singleton with the same current-user factory as [Authenticated tasks](/mcpessentials/guides/authenticated-tasks).
5. Register [`IMcpTaskInputSignalBus`](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus) (Azure Queue or Service Bus) for multi-node `ElicitAsync`. Tables have no native pub/sub.

See [Stores](/mcpessentials/guides/stores).
