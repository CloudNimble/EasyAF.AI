EasyAF SuperIntelligence has different tools to accelerate your SI projects. Pick the one that 's right for you:

<Tabs>
  <Tab title="Build MCP Integrations">
    A generic MCP server that more than one user will call. Start with [MCP Essentials](/mcpessentials).

    ```bash
    dotnet add package McpEssentials.Core
    ```

    Wire authenticated tasks into the official SDK server:

    ```csharp
    using Microsoft.AspNetCore.Http;
    using Microsoft.Extensions.DependencyInjection;

    builder.Services.AddHttpContextAccessor();

    builder.Services.AddMcpServer()
        .WithHttpTransport(o => o.Stateless = true)
        .WithTools<MyTools>()
        .WithTasksPlus(sp => sp.GetRequiredService<IHttpContextAccessor>().HttpContext?.User);
    ```

    Persist those tasks with Entity Framework Core when the process is no longer the store:

    ```bash
    dotnet add package McpEssentials.EntityFrameworkCore
    ```

    Full walkthrough: [Authenticated tasks](/mcpessentials/guides/authenticated-tasks) and [stores](/mcpessentials/guides/stores).
  </Tab>
  <Tab title="Use SI Agents with OData APIs">
    Automagically enables SuperIntelligence harnesses to interact with OData APIs. Start with [OData MCP](/odata-mcp).

    **Remote MCP** — you host the API, customers connect their harness:

    ```bash
    dotnet add package Microsoft.OData.Mcp.AspNetCore
    ```

    **Local MCP** — Install a console-based app that talks to ANY OData v4 service:

    ```bash
    dotnet tool install Microsoft.OData.Mcp --global
    ```

    Local MCP is for you. Remote MCP is what you offer **your** customers at `{prefix}/mcp`.

    Full walkthrough: [Local MCP](/odata-mcp/guides/local) and [Remote MCP](/odata-mcp/guides/remote).
  </Tab>
  <Tab title="Hook Into Claude">
    Utilities that let you hook into Claude operations. Start with [ClaudeEssentials](/claudeessentials).

    ```bash
    dotnet add package ClaudeEssentials
    ```

    Read JSON from stdin, decide, write JSON to stdout:

    ```csharp
    using CloudNimble.ClaudeEssentials.Hooks;
    using CloudNimble.ClaudeEssentials.Hooks.Enums;
    using CloudNimble.ClaudeEssentials.Hooks.Outputs;

    var json = Console.In.ReadToEnd();
    var input = ClaudeHooksSerializer.DeserializePreToolUseInput(json);

    var output = new PreToolUseHookOutput<object>
    {
        Continue = true,
        HookSpecificOutput = new PreToolUseSpecificOutput<object>
        {
            PermissionDecision = input.ToolName is "Read" or "Glob"
                ? PermissionDecision.Allow
                : PermissionDecision.Ask
        }
    };

    Console.WriteLine(ClaudeHooksSerializer.SerializePreToolUseOutput(output));
    ```

    Full walkthrough: [ClaudeEssentials quickstart](/claudeessentials/quickstart).
  </Tab>
</Tabs>

## How to choose

| You are building… | Start here |
|---|---|
| MCP Servers | [McpEssentials](/mcpessentials) |
| OData APIs | [OData MCP](/odata-mcp) |
| Claude policy, context, or quality gates | [ClaudeEssentials](/claudeessentials) |

They compose. A Remote MCP host can use McpEssentials for tasks. Claude Code can call that host. Each library's own docs take it from here.
