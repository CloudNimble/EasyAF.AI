`McpEssentials.AzureTables` is specified and is not in this repository yet.
</Warning>

Cheap point reads for task handles that live minutes. Weak queries. Pair with a queue or Service Bus for elicitation.

<CardGroup cols={2}>
  <Card title="When it ships" icon="circle-check">
    The host already uses Azure Table Storage and wants `PartitionKey = OwnerUserId`, `RowKey = TaskId`.
  </Card>
  <Card title="Until then" icon="globe" href="/mcpessentials/guides/stores/cosmos">
    Cosmos is the shipped Azure document store: partition by owner, native document TTL, index for background complete.
  </Card>
</CardGroup>

## Intended how-to

<Steps>
  <Step title="Add the package">
    Add `McpEssentials.AzureTables`.
  </Step>
  <Step title="Create the tables">
    Tasks table: `PartitionKey = OwnerUserId`, `RowKey = TaskId`. Secondary index `McpTaskIndex` with `PartitionKey = TaskId`, `RowKey = OwnerUserId` so server-side complete can find the owner.
  </Step>
  <Step title="Register the store">
    Singleton, same current-user factory as [Authenticated tasks](/mcpessentials/guides/authenticated-tasks).
  </Step>
  <Step title="Register a bus">
    Tables have no native pub/sub. Register [`IMcpTaskInputSignalBus`](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus) (Azure Queue or Service Bus) for multi-node `ElicitAsync`.
  </Step>
</Steps>
