Edge / IoT / already-on-NATS hosts. JetStream Key/Value holds the canonical record. Core NATS subject `mcp.essentials.task.input` wakes waiting `ElicitAsync` callers.

<CardGroup cols={2}>
  <Card title="When it ships" icon="circle-check">

  </Card>
  <Card title="Until then" icon="bolt" href="/mcpessentials/guides/stores/redis">

  </Card>
</CardGroup>

## Intended how-to

<Steps>
  <Step title="Add the package">
    Add `McpEssentials.Nats` and a NATS connection.
  </Step>
  <Step title="Put the row in KV">
    Each `StoredMcpTask` in a JetStream KV bucket keyed by task id, including `OwnerUserId`.
  </Step>
  <Step title="Register the store">
    Singleton, same current-user factory as [Authenticated tasks](/mcpessentials/guides/authenticated-tasks).
  </Step>
  <Step title="Publish on resolve">
    After a successful resolve, publish task id plus request id on `mcp.essentials.task.input`. Subscribers raise `InputResponseReceived`.
  </Step>
</Steps>

## TTL

KV entry TTL from `DiscardAfter` (`CreatedAt + 2×TimeToLive`).
