<Warning>
`McpEssentials.SqlServer` is specified and is not in this repository yet. Use [Entity Framework Core](/mcpessentials/guides/stores/entity-framework-core) with `UseSqlServer` until it ships.
</Warning>

This package exists for hosts that want Azure SQL or SQL Server **without** an EF model (ADO.NET, Dapper).

<CardGroup cols={2}>
  <Card title="When it ships" icon="circle-check">
    The host already uses `Microsoft.Data.SqlClient` and wants `rowversion` CAS on `McpTasks` under its own migrations.
  </Card>
  <Card title="Until then" icon="table" href="/mcpessentials/guides/stores/entity-framework-core">
    Stay on Entity Framework Core + `UseSqlServer` when you already have a `DbContext`.
  </Card>
</CardGroup>

Service Broker and Query Notifications are heavy; scale-out elicitation pairs Azure SQL with Service Bus as [`IMcpTaskInputSignalBus`](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus).

## Intended how-to

<Steps>
  <Step title="Add the package">
    Add `McpEssentials.SqlServer`.
  </Step>
  <Step title="Create the table">
    `McpTasks` with `rowversion` for compare-and-swap, indexes on `OwnerUserId` and `DiscardAfter`.
  </Step>
  <Step title="Register the store">
    Singleton, same current-user factory as [Authenticated tasks](/mcpessentials/guides/authenticated-tasks).
  </Step>
  <Step title="Optional bus">
    Register [`IMcpTaskInputSignalBus`](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus) for multi-node `ElicitAsync`.
  </Step>
</Steps>

## TTL

Call `SweepExpiredAsync` from a hosted service, or `DELETE WHERE DiscardAfter <= SYSUTCDATETIME()`. `DiscardAfter` is `CreatedAt + 2×TimeToLive`, stamped at write.
