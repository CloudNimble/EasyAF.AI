## Summary

Shared fluent implementation for untyped and typed form builders. Field starters return
a facade for the current field; the next starter, and [FormElicitationBuilderBase.Build](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/FormElicitationBuilderBase#build), stay on the chain.
