## Summary

Base type for authenticated MCP task stores. Wires the current-user callback, fail-closed
identity, [McpTaskStoreBase.InputResponseReceived](/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#inputresponsereceived), flush pulses, and the mapping from
[IMcpTaskStore](/mcpessentials/api-reference/ModelContextProtocol/Extensions/Tasks/IMcpTaskStore) / [IMcpTaskStorePlus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskStorePlus) into per-user core methods.

## Remarks

Subclass and implement the `Core` methods plus `CancellationToken)` to
persist snapshots. Create inserts then pulses a throttled flush; get pulses then reads.
Set [McpTaskStoreBase.AutoSweep](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#autosweep) to [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) and call `CancellationToken)`
from your own job to own the schedule. Override `DateTimeOffset)` to change keep
rules. Do not wrap the SDK `InMemoryMcpTaskStore`; each provider owns its storage.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> DefaultTimeToLive <Badge color="orange">Virtual</Badge>

Gets or sets the default time-to-live for new tasks, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for unlimited.

#### Syntax

```csharp
public virtual System.Nullable<System.TimeSpan> DefaultTimeToLive { get; set; }
```

#### Property Value

Type: `System.Nullable<System.TimeSpan>`

#### Remarks

When set to a positive value, the work window ends at `CreatedAt + TimeToLive` and
the row is discarded at `CreatedAt + 2×TimeToLive` (stamped as
[StoredMcpTask.DiscardAfter](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask#discardafter)), or sooner when a terminal
`GetTaskAsync` serves it. A [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) or non-positive value keeps tasks
until a terminal get or until the store discards them.
