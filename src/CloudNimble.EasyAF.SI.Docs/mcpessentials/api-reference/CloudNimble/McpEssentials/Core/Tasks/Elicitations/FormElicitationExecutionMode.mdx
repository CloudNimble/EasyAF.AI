## Summary

Selects Tasks wrapping from [McpElicitFormAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitFormAttribute) and
[McpElicitUrlAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitUrlAttribute) when Tasks is registered.

## Methods

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Apply

Wraps `ExecutionModeSelector` so a
[McpElicitFormAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitFormAttribute) tool stays on `tools/call`
(`Synchronous`) and a
[McpElicitUrlAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitUrlAttribute) tool is
`Optional`.

#### Syntax

```csharp
public static void Apply(ModelContextProtocol.Extensions.Tasks.McpTasksOptions options)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `options` | `ModelContextProtocol.Extensions.Tasks.McpTasksOptions` | The Tasks options being configured. |

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *options* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Remarks

Form wins when both attributes are present. URL tools wrap only when the client
advertised Tasks on this call, so a waiter can outlive the POST.
