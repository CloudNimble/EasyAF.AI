## Summary

Marks a tool so MCP elicits a named form before the member runs.
`WithTasksPlus` keeps the call on `tools/call` Multi Round-Trip Requests
(`Synchronous`).

## Remarks

Pass the same name to `AddFormElicitation` and `RequireForm`.
Class-level usage applies to every `[McpServerTool]` method on the type.
When both this attribute and [McpElicitUrlAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitUrlAttribute) are present, the form wins.

## Examples

```csharp
[McpServerTool(Name = "ShipOrder")]
[McpElicitForm("ship")]
public static string ShipOrder(RequestContext&lt;CallToolRequestParams&gt; context)
{
    var result = context.RequireForm("ship");
    if (!result.IsAccepted)
    {
        return "Shipping cancelled.";
    }

    return $"Shipped as {result.Content!["trackingNumber"].GetString()}.";
}
```
