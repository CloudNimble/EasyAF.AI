## Properties

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AutoSweep

Gets or sets whether the store pulses a throttled flush after create and on get.

#### Syntax

```csharp
public bool AutoSweep { get; set; }
```

#### Property Value

Type: `bool`
The default is [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool).

#### Remarks

Set to [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) and call `SweepExpiredAsync` from your own job
when you want to own the schedule. The public flush handle always runs a full pass.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> DefaultTimeToLive

Gets or sets the default time-to-live for new tasks, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for unlimited.

#### Syntax

```csharp
public System.Nullable<System.TimeSpan> DefaultTimeToLive { get; set; }
```

#### Property Value

Type: `System.Nullable<System.TimeSpan>`

#### Remarks

When set to a positive value, the work window ends at `CreatedAt + TimeToLive` and
the row is discarded at `CreatedAt + 2×TimeToLive`, or sooner when a terminal get
serves it. A [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) or non-positive value keeps tasks until a terminal
get or until the store discards them.
