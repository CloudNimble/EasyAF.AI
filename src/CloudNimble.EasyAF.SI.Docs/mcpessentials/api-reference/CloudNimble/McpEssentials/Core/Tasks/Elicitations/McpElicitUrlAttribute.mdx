## Summary

Marks a tool so MCP elicits a URL after the member produces one.
`WithTasksPlus` wraps the call as
`Optional` so a
task can outlive the POST while the operator is in the browser.

## Remarks

Constructor arguments name JSON properties on the result that hold URLs
(`connectUri`, `authorizationUrl`, and similar). An empty list leaves the
host to apply its own defaults. Class-level usage applies to every
`[McpServerTool]` method on the type. When [McpElicitFormAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitFormAttribute) is
also present, the form wins and the call stays on `tools/call`.

## Examples

```csharp
[McpServerTool(Name = "Authorize")]
[McpElicitUrl("connectUri")]
public static AuthorizationTicket Authorize()
{
    return ticket;
}
```
