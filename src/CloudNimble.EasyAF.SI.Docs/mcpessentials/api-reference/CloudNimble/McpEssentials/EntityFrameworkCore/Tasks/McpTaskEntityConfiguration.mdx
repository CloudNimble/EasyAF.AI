## Summary

Maps [McpTaskEntity](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/McpTaskEntity) to a table (default `McpTasks`) with owner, work-window,
and discard indexes and an application-managed concurrency token. Protocol enums and payloads
convert to strings. [StoredMcpTask.DiscardAfter](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/StoredMcpTask#discardafter) stores UTC ticks so every
provider, including SQLite, can `ExecuteDelete` on the stamp.
