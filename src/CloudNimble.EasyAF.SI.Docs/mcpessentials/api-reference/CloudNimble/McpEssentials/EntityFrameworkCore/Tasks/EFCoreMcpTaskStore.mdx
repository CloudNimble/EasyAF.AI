## Summary

An [IMcpTaskStorePlus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskStorePlus) that persists snapshots on
`TContext.Set&lt;McpTaskEntity&gt;()`. Register as a singleton. The host registers
*TContext* as scoped (standard `AddDbContext`); this store opens
a scope per operation.

## Remarks

Client-facing operations require a current user and treat another user's task as missing.
Server-side completion skips the live-user check. Optional [IMcpTaskInputSignalBus](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/IMcpTaskInputSignalBus)
fans [McpTaskStoreBase.InputResponseReceived](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/McpTaskStoreBase#inputresponsereceived) out to other nodes.
The SDK `WithTasks` API captures the store instance before `Build()`; use
`WithTasksPlus` so the provider is stamped on first use.

## Type Parameters

- `TContext` - The host [DbContext](https://learn.microsoft.com/dotnet/api/microsoft.entityframeworkcore.dbcontext). Map [McpTaskEntity](/mcpessentials/api-reference/CloudNimble/McpEssentials/EntityFrameworkCore/Tasks/McpTaskEntity) with
`ModelBuilder.AddMcpTasksTable` in `OnModelCreating`, or with
`DbContextOptionsBuilder.AddMcpTasksTable` from `AddDbContext` when the context
project must not reference this package.
