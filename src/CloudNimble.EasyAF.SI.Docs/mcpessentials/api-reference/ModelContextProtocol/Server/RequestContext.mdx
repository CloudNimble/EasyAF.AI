### <Icon icon="puzzle-piece" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> RequireForm <Badge color="green">Extension</Badge>

<Note>Extension method from `ModelContextProtocol.Server.McpEssentials_Core_RequestContextExtensions`</Note>

Resolves the named form from `Services` and
either returns the client's answer or throws `InputRequiredException`.

#### Syntax

```csharp
public static ModelContextProtocol.Protocol.ElicitResult RequireForm(ModelContextProtocol.Server.RequestContext<ModelContextProtocol.Protocol.CallToolRequestParams> context, string name)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `context` | `ModelContextProtocol.Server.RequestContext<ModelContextProtocol.Protocol.CallToolRequestParams>` | The current `tools/call` context. |
| `name` | `string` | The name passed to `AddFormElicitation`. |

#### Returns

Type: `ModelContextProtocol.Protocol.ElicitResult`
The elicitation result from the retry.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *context* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `ArgumentException` | Thrown when *name* is empty. |
| `InvalidOperationException` | Thrown when the server has no service provider, or no form is registered under *name*. |
| `InputRequiredException` | Thrown when the client has not answered yet. |

#### Examples

```csharp
[McpServerTool(Name = "ShipOrder")]
[McpElicitForm("ship")]
public static string ShipOrder(RequestContext&lt;CallToolRequestParams&gt; context)
{
    var result = context.RequireForm("ship");
    if (!result.IsAccepted)
    {
        return "Shipping cancelled.";
    }

    return $"Shipped as {result.Content!["trackingNumber"].GetString()}.";
}
```

#### Remarks

Pair this with [McpElicitFormAttribute](/mcpessentials/api-reference/CloudNimble/McpEssentials/Core/Tasks/Elicitations/McpElicitFormAttribute) so `WithTasksPlus` keeps the call synchronous.
