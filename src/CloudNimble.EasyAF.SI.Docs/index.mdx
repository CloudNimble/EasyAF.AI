EasyAF SuperIntelligence is a set of independent .NET libraries that help you build innovative solutions for modern SuperIntelligence apps faster
than ever before. 

[.NET](https://dotnet.microsoft.com) is the most powerful and most performant platform for your SI-connected apps.

Every library here is Native AOT optimized for near-native startup and throughput. Pair them with [McMaster.Extensions.CommandLine](https://github.com/natemcmaster/CommandLineUtils) 
and you ship lightning-fast local or remote MCP servers, tools that watch the AI harnesses your company already deploys, and APIs an SI can read 
without flailing around like a fish out of water.

## Three standalone tools

Each of these libraries work independently to help you ship solutions faster.

## Better Together

Use these tools with the rest of the [EasyAF](https://easyaf.dev) platform and you get SuperIntelligent APIs: agents log in automatically, get your 
data for you, and execute tasks more effectively... faster than ever before.

Layer [OData MCP](/odata-mcp) on that API. It already uses [MCP Essentials](/mcpessentials) for authenticated, durable tasks. The assistant gets a 
compact catalog instead of a 4,000-token `$metadata` dump, so it hits the right entity set the first time. Your customers succeed more often. A flailing 
agent stops hammering every endpoint and burning tokens trying to learn your shape.
