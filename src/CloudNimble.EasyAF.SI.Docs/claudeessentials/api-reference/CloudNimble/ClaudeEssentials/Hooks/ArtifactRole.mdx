## Summary

Represents the role the user holds on a shared artifact.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Editor` | 0 | The user can edit the artifact. |
| `Commenter` | 1 | The user can comment on the artifact. |
| `Reader` | 2 | The user can read the artifact. |
| `Viewer` | 3 | The user can view the artifact. |
