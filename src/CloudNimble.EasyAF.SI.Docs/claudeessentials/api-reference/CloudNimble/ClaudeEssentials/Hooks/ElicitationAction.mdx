## Summary

Represents the action to take for an elicitation dialog response.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Accept` | 0 | Accept the elicitation dialog with the provided form values. |
| `Decline` | 1 | Decline the elicitation dialog. |
| `Cancel` | 2 | Cancel the elicitation dialog entirely. |
